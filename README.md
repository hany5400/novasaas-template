# 🚀 NovaAI — Modern AI & SaaS Landing Page Template

Thank you for purchasing **NovaAI**! This is a production-ready, high-converting dark mode landing page crafted for AI startups, SaaS products, developer tools, and modern web applications.

## 📦 What's Included

* `index.html` — Fully semantic, accessible, SEO-optimized landing page.

## ⚡ Quick Start (No Node.js Required)

You do **not** need Node.js or complex build tools to use this template:
1. Double-click `index.html` to open and preview the website directly in any web browser.
2. Edit the text and images using your favorite code editor (VS Code, Sublime, etc.).

---

## 🎨 How to Customize

### 1. Change Colors & Brand
Inside `index.html`, we use standard Tailwind CSS classes. You can change the primary brand color in `tailwind.config` in the `<head>` tag:
```html
colors: {
  brand: {
    500: '#6366f1', // Replace with your hex color
  }
}
```

### 2. Replace Copy & Headlines
All sections have clear HTML comment tags:
* `<!-- ================= HERO SECTION ================= -->`
* `<!-- ================= BENTO GRID FEATURES ================= -->`
* `<!-- ================= PRICING SECTION ================= -->`
* `<!-- ================= FAQ SECTION ================= -->`

Simply search for those comments and replace the text with your own product details.

### 3. Deploy in 60 Seconds
* **Vercel / Netlify:** Drag and drop the folder directly into [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
* **GitHub Pages:** Push to a repository and turn on GitHub Pages in repository settings.
